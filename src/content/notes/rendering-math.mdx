# 3D Projection Mathematics

To render a 3D object onto a 2D screen (like in our React Three Fiber viewer), we use projection matrices. Here is how the math works in Python.

We can simulate the projection logic using Python and NumPy directly in the browser.

<PythonREPL 
  packages={['numpy']}
  code={`import numpy as np

def perspective_projection(point_3d, d=1):
    x, y, z = point_3d
    # Avoid division by zero
    if z == 0: z = 0.001
    return np.array([x / (z/d), y / (z/d)])

# Define a simple 3D point
point = np.array([10, 10, 20])
projected = perspective_projection(point)

print(f"3D Point: {point}")
print(f"2D Projected: {projected}")`} 
/>

The formula used above is a simplified version of the perspective projection matrix used in WebGL:

$$
x' = \frac{x}{z/d}, \quad y' = \frac{y}{z/d}
$$

Where $d$ is the distance to the projection plane.
