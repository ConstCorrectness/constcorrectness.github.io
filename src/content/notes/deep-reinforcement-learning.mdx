# Deep Reinforcement Learning

Reinforcement learning is the study of decision-making under uncertainty. An **agent** observes a **state** $s_t$, takes an **action** $a_t$, receives a **reward** $r_t$, and transitions to a new state $s_{t+1}$. The goal is to find a **policy** $\pi(a \mid s)$ that maximises expected cumulative reward.

Unlike supervised learning, there is no labelled dataset — the agent must discover what works by trying things and observing the consequences.

## The Bellman Equation

The central object is the **action-value function** $Q^\pi(s, a)$: the expected return when starting in state $s$, taking action $a$, and following policy $\pi$ thereafter.

The optimal $Q^*$ satisfies the Bellman optimality equation:

$$
Q^*(s, a) = \mathbb{E}\!\left[\, r + \gamma \max_{a'} Q^*(s', a') \;\middle|\; s, a \right]
$$

The discount factor $\gamma \in [0, 1)$ makes the agent prefer sooner rewards — an infinite horizon collapses to a finite sum. This equation is recursive: the value of taking action $a$ in state $s$ is the immediate reward plus the best possible discounted future value.

## Q-Learning

Q-learning (Watkins, 1989) is a model-free algorithm that directly approximates $Q^*$ using a table. After each transition $(s, a, r, s')$, it nudges the current estimate toward the Bellman target:

$$
Q(s, a) \;\leftarrow\; Q(s, a) + \alpha \underbrace{\Big[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \Big]}_{\text{TD error}}
$$

The bracketed term is the **temporal-difference (TD) error** — how wrong the current estimate is compared to a one-step lookahead. $\alpha$ is the learning rate.

### Exploration vs. Exploitation

A greedy policy always picks $\arg\max_a Q(s,a)$, but early in training the Q-table is noise. The standard fix is **$\varepsilon$-greedy**: with probability $\varepsilon$ choose a random action, otherwise act greedily. $\varepsilon$ decays over training as the estimates become trustworthy.

## Training in Python

Here is Q-learning from scratch on a 5×6 gridworld (same layout as the interactive demo below). The agent starts at `S`, must reach `G`, and walls block movement.

## From Tables to Networks

Q-learning with a table works when the state space is small enough to enumerate. Real problems — Atari games, robot control — have states in the millions or continuous. The fix is the **Deep Q-Network (DQN)**: replace the table $Q(s, a)$ with a neural network $Q_\theta(s, a)$ parameterised by weights $\theta$.

The same TD update applies, now via gradient descent:

$$
\mathcal{L}(\theta) = \mathbb{E}\!\left[\left( r + \gamma \max_{a'} Q_{\bar\theta}(s', a') - Q_\theta(s, a) \right)^{\!2}\right]
$$

The target network $Q_{\bar\theta}$ is a frozen copy of $Q_\theta$, updated periodically — this stabilises training by breaking the moving-target problem inherent in bootstrapped updates.
